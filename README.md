# RS3-Status-Bars

This is a re-creation of my own "[More Status Bars](https://github.com/Avexiis/MoreStatusBars)" RuneLite plugin, but made for the new RuneScape 3 plugin API.

Displays different status bars for:
> - Constitution
> - Prayer
> - Run energy
> - Summoning points
> - Special attack
> - Adrenaline

It is a floating widget, as opposed to RuneLite's tab-locked widget. Adrenaline and Special Attack use the same slot, depending on the user's combat mode.

It can be displayed horizontally, not just vertically.
