
Status Bars
-
Displays different status bars for:
- Constitution
- Prayer
- Run energy
- Summoning points
- Special attack
- Adrenaline

Adrenaline and Special Attack use the same slot, depending on the user's combat mode.

It can be displayed horizontally and vertically.

Permissions
-
Status bars requires no permissions.

Data Protection
-
Status Bars uses the following information to provide its functionality:

Player health
Player run energy
Player prayer points
Player summoning points
Player adrenaline/special attack

Player info is not kept persistently by the plugin, only user-selected settings are stored.
